##################
Basic Requirements
##################

This section describes how to install the basic requirements of |eddsrecorder|.
Once they are met, please refer to :ref:`installation_manual_windows` or :ref:`installation_manual_linux` to install
the application itself.

***************************
Windows 7 32-bit and 64-bit
***************************

Visual C++ 2010 Redistributable package
=======================================

|eddsrecorder| requires the *Visual C++ 2010 Redistributable* package.
The distributed installer checks whether the package is present in the system and, if it is not, prompts the user to
install it.

*******************
Linux distributions
*******************

Boost
=====

|eddsrecorder| uses the `Boost <https://www.boost.org/>`_ libraries.
Install them using the package manager of the corresponding Linux distribution.
For example, on Debian based distributions use the command:

.. code-block:: bash

    sudo apt install libboost-all-dev

An external sniffer
===================

|eddsrecorder| does not capture the network traffic itself: it parses a :term:`PCAP` file previously generated by a
network sniffer.
Any sniffer able to write standard packet capture files, such as `Wireshark <https://www.wireshark.org/>`_, may be used.
